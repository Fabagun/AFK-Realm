# AFK Realm

*Уходи в AFK – возвращайся на свой собственный сервер.*

> [!WARNING]
> **В разработке и очень экспериментально.** AFK Realm не закончен и постоянно меняется. Каждую версию и каждую новую функцию стоит считать экспериментальной. Делайте резервные копии всего важного (AFK Realm делает копию перед каждым обновлением и изменением модулей) и сообщайте о проблемах, приложив `logs\install.log`.

Собирайте, запускайте и настраивайте собственный сервер **Conquest of Azeroth** (форк AzerothCore с Playerbots) под Windows 10/11 – прямо из исходного кода, всё парой щелчков мыши.

![](docs/screenshots/8-server-management.png)

Это краткая версия. Полное описание – в [английском README](README.md), руководство пользователя – в [docs/MANUAL.md](docs/MANUAL.md) (на английском). Сама программа на русском: она запускается на языке Windows, язык переключается справа вверху.

## Что умеет AFK Realm

- **Пошаговая установка**: выберите папку и пароль базы данных, нажмите *Установить* – Git, CMake, Visual Studio Build Tools, OpenSSL, Boost, MySQL и Python AFK Realm скачает сам
- **Всегда актуально**: каждая установка собирает свежее ядро CoA и Playerbots; обновления с резервной копией перед ними
- **Сервер под контролем**: запуск, остановка, перезапуск, перезапуск по расписанию, обе консоли сервера в одном окне
- **Настройки** всех конфигурационных файлов, с поиском, описанием и значением по умолчанию
- **Боты, учётные записи и инструменты ГМ**: обзор случайных ботов, создание и перенос учётных записей, починка заданий, помощь персонажам
- **Модули** добавляются и удаляются одним щелчком вместе с их изменениями в базе данных – среди них World Journey (мир как одно путешествие от 1 до 60), боты аукциона, новые расы и классические классы
- **Игра с другими**: адрес мира, аддоны и клиентский патч одним ZIP для ваших игроков
- **На вашем языке**: русский, английский, немецкий, французский, испанский, португальский (Бразилия) и упрощённый китайский; другие языки можно добавить файлом

## Начало работы

1. Скачайте `AFK-Realm.exe` со страницы [Releases](../../releases) и запустите. Windows SmartScreen может предупредить о неизвестном издателе, потому что exe не подписан; его собирает GitHub Actions из этого репозитория.
2. **Установить новый сервер** → выберите папку, например `C:\CoA-Server` → задайте пароль базы данных → **Установить**. Это может занять много времени и требует около 40 ГБ места.
3. В управлении сервером: *Создать данные карт из игрового клиента* (один раз), *Создать учётную запись*, *Запустить сервер*.
4. Впишите `set realmlist 127.0.0.1` в `realmlist.wtf` вашего клиента и войдите.

Игровой клиент CoA нужен свой; он не входит в этот проект.
